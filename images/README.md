# Neon Café Images

## Place Your Images Here

This folder should contain all images for the Neon Café website.

### Required Files:

```
images/
├── logo.png (or .jpg)      # The neon café gradient logo
├── hero.jpg                 # Interior with pink neon lights and sign
├── about.jpg                # Coffee and brownie on green velvet
└── gallery/
    ├── gallery-1.jpg        # Coffee and brownie scene
    ├── gallery-2.jpg        # Iced coffee with branding
    ├── gallery-3.jpg        # Customer with neon rainbow
    ├── gallery-4.jpg        # Dessert slice 1
    ├── gallery-5.jpg        # Dessert slice 2
    └── gallery-6.jpg        # Additional café photo
```

## From Your Uploaded Images:

1. **Logo**: First image (gradient background with neon café text)
2. **Hero**: Second image (interior with circular neon sign)
3. **About**: Third image (coffee and brownie on green chair)
4. **Gallery 1**: Third image (coffee scene)
5. **Gallery 2**: Fourth image (iced coffee)
6. **Gallery 3**: Fifth image (woman with neon rainbow)
7. **Gallery 4**: Sixth image (tart slice)
8. **Gallery 5**: Seventh image (dessert slice)
9. **Gallery 6**: Any additional photo from your collection

## How to Add Images:

1. Download the images you uploaded to the conversation
2. Rename them according to the structure above
3. Place them in this `images/` folder and the `images/gallery/` subfolder
4. Commit and push: `git add images/ && git commit -m "Add Neon Café images" && git push`

The `config.js` file is already configured to use these local paths!
